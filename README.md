# React CSV, XML, JSON importer and exporter

This project is there as an example on how to import and export files in format CSV, XML and JSON.

This is the result in [https://tcrurav.github.io/react-import-export-json-xml-csv/](https://tcrurav.github.io/react-import-export-json-xml-csv/)


## Prerequisites

You need a working environment with:
* [Git](https://git-scm.com) - You can install it from https://git-scm.com/downloads.
* [Node](https://nodejs.org) - Install node.js from https://nodejs.org/es/download/. It's advisable to install the LTS version.
* [React JS][https://legacy.reactjs.org/] - A JavaScript library for building user interfaces

## General instructions to try this project locally

Clone this project:

```
git clone https://github.com/tcrurav/react-import-export-json-xml-csv.git
```

Now install all dependencies.

```
cd react-import-export-json-xml-csv
npm install
```

Run the project to see the resulting page:

```
npm run dev
```

Enjoy!!!
